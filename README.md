# Transformer для машинного перевода De → En

Учебный проект курса «Введение в глубинное обучение» (НИУ ВШЭ): encoder–decoder трансформер для перевода с немецкого на английский на PyTorch.

**Результат:** BLEU 31.9 на валидации (sacreBLEU, greedy-декодинг).

## Модель
- Encoder–decoder трансформер (`nn.Transformer`): 3 + 3 слоя, d_model = 256, 8 голов внимания, FFN 1024, ~30M параметров
- Синусоидальные позиционные кодировки, padding- и causal-маски
- Словари на уровне слов (до 32k токенов, min_freq = 2)

## Обучение
- ~196 тыс. пар предложений, 25 эпох на одном GPU (Kaggle), ~5 минут на эпоху
- Adam (β = 0.9, 0.98), lr = 3e-4, label smoothing 0.1, gradient clipping 1.0
- Чекпоинт выбирается по BLEU на валидации

| Эпоха | 3 | 6 | 9 | 12 | 15 | 25 |
|---|---|---|---|---|---|---|
| Val BLEU | 24.4 | 29.6 | 30.4 | 31.0 | **31.9** | 31.9 |

## Запуск
pip install -r requirements.txt

Открыть `transformer_de_en.ipynb` и поменять `Config.data_dir` на путь к данным (файлы `train/val/test.de-en.{de,en}`, токенизированный текст через пробел).

## Возможные улучшения
- Beam search вместо greedy-декодинга
- Сабворд-токенизация (BPE) вместо словаря на уровне слов: убрала бы `<unk>` в переводах
- Warmup + inverse sqrt / cosine расписание learning rate
